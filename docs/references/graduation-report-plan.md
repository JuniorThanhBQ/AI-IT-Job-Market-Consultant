## The project implementation plan is organized into 5 phases:
- **From July 6, 2026 – July 19, 2026**: Synthesize research documents on AI Agents
and hybrid retrieval, RAG, and reranking techniques. Survey recruitment platforms
ITViec, TopDev, ITJobs, and VietnamWorks to understand DOM structure, data mining methods, and legal documents. The completion of this phase will achieve
the results of objective 1.
- **From July 20, 2026 – August 2, 2026**: Design and build an automation flow
using Celery with core tasks including web scraping and data embedding from
the four platforms, updating job posting status, and periodic backups. The results are the second objective of the project.
- **From August 3rd, 2026 – August 16th, 2026**: Design and build the AI ​​Agent using the ReAct model, along with the techniques mentioned in objective 3. Simultaneously, develop the frontend interface for the web app. The result of this phase is a summary report, version 1.
- **From August 17th, 2026 – August 30th, 2026**: Complete web app development with the main functionalities according to the Use Case specification, integrating the AI ​​Agent and Celery. The end of this phase is a summary report, version 2.
- **From August 31st, 2026 – September 13th, 2026**: Simulate deployment using ngrok to evaluate the latency,accuracy of hybrid retrieval, RAG and reranking, and perform acceptance testing. Next, deploy the system in practice via the cloud platform Vercel, Render, and Supabase. Complete the final report (full version).
