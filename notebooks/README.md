[02_crawler_data_exploration.ipynb](https://colab.research.google.com/drive/1i6xw2lPQOrV69IkIisEE8dgkbmtTehyF?usp=sharing)

AIJMC utilizes Google Colab and PostgreSQL backup dump files stored on Google Drive to conduct Exploratory Data Analysis (EDA). This evaluation aims to verify whether the crawler produces the expected results after operating over an extended period.

Details regarding the formulas used to evaluate the dataset as implemented in `01_crawler_data_quality_rating.ipynb` are provided in the thesis report.

Note: Those two notebooks are intended solely for evaluating the dataset after a specific crawling period. The project provides the source code only and does not offer support for executing the notebooks.
